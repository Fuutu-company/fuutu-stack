---
title: Tabs
description: Tabbed-Inhalt für mehrere Optionen oder Sprachen.
tags: ["components", "tabs"]
---

Tabs lassen dich mehrere Optionen in einem kompakten Raum zeigen. Sie eignen sich
hervorragend für mehrsprachige Code-Beispiele.

## Grundlegende Tabs

<Tabs items={["npm", "pnpm", "yarn"]}>
	<Tab value="npm">
```bash
npm install
```
  </Tab>
	<Tab value="pnpm">
```bash
pnpm install
```
  </Tab>
	<Tab value="yarn">
```bash
yarn install
```
  </Tab>
</Tabs>

## Mit Standard-Index

<Tabs items={["TypeScript", "JavaScript"]} defaultIndex={1}>
	<Tab value="TypeScript">
```ts
const x: number = 42;
```
  </Tab>
	<Tab value="JavaScript">
```js
const x = 42;
```
  </Tab>
</Tabs>

## Gruppierte Tabs

Tabs mit derselben `groupId` teilen sich ihren ausgewählten Index über Seiten hinweg:

<Tabs items={["Vite", "Webpack"]} groupId="bundler">
	<Tab value="Vite">
```bash
npx vite build
```
  </Tab>
	<Tab value="Webpack">
```bash
npx webpack --mode production
```
  </Tab>
</Tabs>

## Verwendung

```mdx
<Tabs items={["Option A", "Option B"]}>
  <Tab value="Option A">
    Inhalt für Option A.
  </Tab>
  <Tab value="Option B">
    Inhalt für Option B.
  </Tab>
</Tabs>
```
