Der interaktive API-Playground wird unter `/[locale]/openapi` bereitgestellt. Jeder
Endpunkt aus der OpenAPI-Spezifikation erhält seine eigene Seite mit:

- Anfrage/Antwort-Schema-Anzeige
- Code-Beispielen in mehreren Sprachen
- Try-it-out-Playground (erfordert `@scalar/api-client-react`)

## Verfügbare Endpunkte

### Auth

- `POST /auth/sign-in` — Authentifizierung mit E-Mail und Passwort
- `POST /auth/sign-up` — Neues Konto erstellen

### Organisationen

- `GET /organizations` — Organisationen des Benutzers auflisten
- `POST /organizations` — Neue Organisation erstellen
- `GET /organizations/{slug}` — Organisation nach Slug abrufen

### Billing

- `POST /billing/checkout` — Polar-Checkout-Sitzung erstellen
- `GET /billing/subscription` — Aktuelles Abonnement abrufen
