## Grundlegendes Markdown

Standard-Markdown funktioniert sofort:

- **Fetter** Text
- *Kursiver* Text
- ~~Durchgestrichener~~ Text
- `Inline-Code`
- [Links](https://fumadocs.dev)

> Blockquotes werden ebenfalls unterstützt.
