Die Dokumentations-App verwendet **CSS-Variablen** für Theming, mit Dark Mode powered by
`next-themes`.

## Dark Mode

Dark Mode wird vom `ThemeProvider` in
`src/modules/shared/providers/theme-provider.tsx` gehandhabt:

```tsx title="src/modules/shared/providers/theme-provider.tsx"
"use client";
import { config } from "@fuutu/config";
import { ThemeProvider as NextThemesProvider } from "next-themes";

export function ThemeProvider({ children }) {
  return (
    <NextThemesProvider
      attribute="class"
      defaultTheme={config.theme.defaultMode}
      enableSystem={false}
      disableTransitionOnChange
    >
      {children}
    </NextThemesProvider>
  );
}
```

<Callout type="info">
  Das Standard-Theme wird von `config.theme.defaultMode` in
  `@fuutu/config` gesteuert. Ändere es dort, um alle Apps zu beeinflussen.
</Callout>

## CSS-Variablen

Fumadocs verwendet `--color-fd-*` CSS-Variablen. Das Theme wird aus zwei Quellen importiert:

1. **Fuutu-Stack-Theme**: `@fuutu/config/theme.css` — gemeinsam für alle Apps
2. **Fumadocs-shadcn-Theme**: `fumadocs-ui/css/shadcn.css` — bildet die gemeinsamen shadcn-Tokens auf `--color-fd-*` ab

```css title="src/app/global.css"
@import "tailwindcss";
@import "@fuutu/config/theme.css";
@import "fumadocs-ui/css/shadcn.css";
@import "fumadocs-ui/css/preset.css";
@import "fumadocs-openapi/css/preset.css";

:root,
.dark {
  --color-fd-info: var(--info);
  --color-fd-warning: var(--warning);
  --color-fd-success: var(--success);
  --color-fd-error: var(--destructive);
}
```

Der zweite Block bildet die Statusfarben des Kits auf die Fumadocs-Callout-Farben ab.
Um die Palette zu ändern, bearbeite `packages/config/brand.css`.

`brand.css` enthält außerdem die vier Produktbereich-Tokens (`--area-users`, `--area-billing`,
`--area-ai`, `--area-api`, jeweils mit einer `-foreground`-Tinte). Die Docs-App erbt sie
zusammen mit dem Primary, der Tinte ist. Schriften werden in `src/app/fonts.ts` geladen und
über `--font-sans`, `--font-heading` und `--font-mono` bereitgestellt.

## Farben anpassen

Um Fumadocs-Farben zu überschreiben, füge CSS-Variablen in `global.css` hinzu:

```css title="src/app/global.css"
:root {
  --color-fd-primary: oklch(0.55 0.25 260);
}

.dark {
  --color-fd-primary: oklch(0.65 0.25 260);
}
```
