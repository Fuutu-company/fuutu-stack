Willkommen zur **Fuutu-Stack-Dokumentationsvorlage** — eine produktionsreife
Dokumentations-App, die mit Fumadocs, Next.js und Tailwind CSS erstellt wurde.

## Warum diese Vorlage?

<Callout type="info">
  Dies ist ein **Starter-Baustein**. Jede Seite ist ein eigenständiges Beispiel.
  Lösche, was du nicht brauchst, und ersetze es durch deinen eigenen Inhalt.
</Callout>

## Was ist enthalten

| Feature | Status |
