This is the **docs template** bundled with the Fuutu Stack. It showcases every
Fumadocs feature as a modifiable example — delete what you don't need, keep
what you do.

## Quick start

Add MDX files to `apps/docs/content/docs/en/` and they appear in the sidebar
automatically. Use `meta.json` files to control navigation order, titles, and
icons.

```mdx title="content/docs/en/getting-started/introduction.mdx"
---
title: Introduction
description: Your first docs page.
---

# Hello World

Write **Markdown** and use <Callout>components</Callout> inline.
```
