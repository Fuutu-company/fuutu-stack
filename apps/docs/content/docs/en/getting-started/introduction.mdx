Welcome to the **Fuutu Stack docs template** — a production-ready
documentation app built with Fumadocs, Next.js, and Tailwind CSS.

## Why this template?

<Callout type="info">
  This is a **starter building block**. Every page is a self-contained
  example. Delete what you don't need and replace with your own content.
</Callout>

## What's included

| Feature | Status |
|---------|--------|
| MDX content | ✅ Ready |
| Full-text search | ✅ Ready |
| Dark mode | ✅ Ready |
| i18n (en/de) | ✅ Ready |
| OpenAPI docs | ✅ Ready |
| OG image generation | ✅ Ready |
| LLM-friendly routes | ✅ Ready |
| Kit fingerprint | ✅ Ready |
