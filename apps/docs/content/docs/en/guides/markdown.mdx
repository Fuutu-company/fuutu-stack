This page demonstrates **every MDX feature** available in the Fuutu Stack docs
template. Use it as a reference when writing your own content.

## Basic Markdown

Standard Markdown works out of the box:

- **Bold** text
- *Italic* text
- ~~Strikethrough~~ text
- `inline code`
- [Links](https://fumadocs.dev)

> Blockquotes are supported too.
