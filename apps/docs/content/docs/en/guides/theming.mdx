The docs app uses **CSS variables** for theming, with dark mode powered by
`next-themes`.

## Dark mode

Dark mode is handled by the `ThemeProvider` in
`src/modules/shared/providers/theme-provider.tsx`:

```tsx title="src/modules/shared/providers/theme-provider.tsx"
"use client";
import { config } from "@fuutu/config";
import { ThemeProvider as NextThemesProvider } from "next-themes";

export function ThemeProvider({ children }) {
  return (
    <NextThemesProvider
      attribute="class"
      defaultTheme={config.theme.defaultMode}
      enableSystem={false}
      disableTransitionOnChange
    >
      {children}
    </NextThemesProvider>
  );
}
```

<Callout type="info">
  The default theme is controlled by `config.theme.defaultMode` in
  `@fuutu/config`. Change it there to affect all apps.
</Callout>

## CSS variables

Fumadocs uses `--color-fd-*` CSS variables. The theme is imported from two
sources:

1. **Fuutu Stack theme**: `@fuutu/config/theme.css` — shared across all apps
2. **Fumadocs shadcn theme**: `fumadocs-ui/css/shadcn.css` — maps the shared shadcn tokens onto `--color-fd-*`

```css title="src/app/global.css"
@import "tailwindcss";
@import "@fuutu/config/theme.css";
@import "fumadocs-ui/css/shadcn.css";
@import "fumadocs-ui/css/preset.css";
@import "fumadocs-openapi/css/preset.css";

:root,
.dark {
  --color-fd-info: var(--info);
  --color-fd-warning: var(--warning);
  --color-fd-success: var(--success);
  --color-fd-error: var(--destructive);
}
```

The second block maps the kit's status colors onto the Fumadocs callout colors.
To change the palette, edit `packages/config/brand.css`.

`brand.css` also holds the four product-area tokens (`--area-users`, `--area-billing`,
`--area-ai`, `--area-api`, each with a `-foreground` ink). The docs app inherits them
along with the primary, which is ink. Fonts are loaded in `src/app/fonts.ts` and exposed
through `--font-sans`, `--font-heading` and `--font-mono`.

## Customizing colors

To override Fumadocs colors, add CSS variables in `global.css`:

```css title="src/app/global.css"
:root {
  --color-fd-primary: oklch(0.55 0.25 260);
}

.dark {
  --color-fd-primary: oklch(0.65 0.25 260);
}
```
